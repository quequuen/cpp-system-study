## 가상 메모리 (Virtual Memory)

프로세스가 실제 물리 메모리(RAM)의 위치를 전혀 몰라도, 마치 자기만의 독립된 메모리 공간을 통째로 가진 것처럼 보이게 해주는 OS의 추상화 기법. [`thread.md`의 프로세스](./thread.md#프로세스-process)에서 다룬 **독립된 메모리 구조**가 실제로 격리되는 하부 메커니즘이 바로 이것.

### 논리 주소 (Logical Address) vs 물리 주소 (Physical Address)

- **논리 주소 (Logical Address)** 또는 **가상 주소 (Virtual Address)**
  CPU와 프로그램이 다루는 주소. 코드에서 포인터로 찍히는 주소(`&x` 등)는 전부 이 논리 주소임. 각 프로세스는 0번지부터 시작하는 자기만의 주소 공간을 따로 가짐.
- **물리 주소 (Physical Address)**
  실제 RAM 칩 위의 위치. 프로그램은 이 주소를 직접 알 수 없고, 알 필요도 없음.

```
Process A                   Process B
논리 주소 0x1000             논리 주소 0x1000   ← 서로 똑같은 번지를 가질 수 있음
     │                            │
     ▼ (MMU가 변환)                ▼ (MMU가 변환)
물리 주소 0x7F3A00           물리 주소 0x82C100   ← 실제로는 전혀 다른 RAM 위치
```

두 프로세스가 완전히 같은 논리 주소를 들고 있어도, 실제로 가리키는 물리 메모리는 서로 다르기 때문에 한 프로세스가 다른 프로세스의 메모리를 건드릴 수 없음 (프로세스 격리).

### MMU (Memory Management Unit)

CPU가 논리 주소로 메모리에 접근할 때마다, 그 요청을 가로채서 물리 주소로 바꿔주는 **하드웨어**. 모든 메모리 접근마다 발생하는 변환 작업이라 소프트웨어로 처리하면 너무 느리기 때문에, CPU 안에 내장된 전용 회로(CPU 패키지)가 처리함.

```
CPU가 요청한 논리 주소
      ↓
    [ MMU ]  ← 페이지 테이블을 참조해서 변환
      ↓
   물리 주소
      ↓
   실제 RAM 접근
```

### 페이지 테이블 (Page Table)

MMU가 변환할 때 참조하는 논리 주소와 매칭되는 물리 주소의 매핑 테이블. **프로세스마다 하나씩 따로 가짐.** 그래서 서로 다른 논리 주소 공간이 서로 다른 물리 주소로 매핑될 수 있는 것.

- 메모리를 바이트 단위가 아니라 **페이지(Page)**라는 고정 크기 블록 단위로 관리함. (보통 4KB, Apple Silicon은 16KB)
- 물리 메모리 쪽의 같은 크기 블록은 **프레임(Frame)**이라고 부름.
- 즉 페이지 테이블은 정확히는 **페이지 번호 → 프레임 번호**의 매핑이고, 여기에 페이지 안에서의 offset을 그대로 더해 최종 물리 주소가 나옴.

```
논리 주소 = [ 페이지 번호 | 페이지 내 offset ]
                  │              │
                  ▼ (페이지 테이블 조회)      │
            [ 프레임 번호 ]       │
                  │              │
                  ▼              ▼ (그대로 유지)
물리 주소 = [ 프레임 번호 | 페이지 내 offset ]
```

### TLB (Translation Lookaside Buffer)

페이지 테이블은 메인 메모리에 있어서, 매번 조회하면 메모리 접근이 두 번(테이블 조회 + 실제 데이터 접근) 필요해져 느려짐. TLB는 CPU 안에 있는 **최근 변환 결과를 캐싱해두는 작은 고속 캐시**. 변환하려는 페이지 번호가 TLB에 있으면(TLB Hit) 페이지 테이블 조회 없이 바로 물리 주소를 얻어 속도가 빨라짐.

---

> 페이지 단위로 메모리를 들여오고 내보내는 과정(데맨드 페이징)이나, 페이지가 부족해서 디스크로 밀어내는 과정에서 발생하는 **스래싱(Thrashing)**은 [`thread.md`의 멀티 스레드](./thread.md#멀티스레드) 섹션에 먼저 정리되어 있음.
